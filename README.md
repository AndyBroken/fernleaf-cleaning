# Fernleaf Home Cleaning — Basic Package (Concept)

One-page landing site for a house cleaning company in Raleigh, NC.

**Includes:** sticky header with click-to-call, hero with live "next available" slot, trust bar, 6 service cards, how-it-works steps, flat-rate pricing with one-time / monthly / bi-weekly / weekly discount toggle, gallery with lightbox, reviews, service area map with ZIP checker, FAQ, instant quote form with live price estimate and validation, sticky mobile "Call / Quote" bar, scroll animations. Fully responsive.

**Tech:** HTML5, CSS3, vanilla JavaScript — a single file, no build step. Photos: Unsplash.

*Concept / demo project — Fernleaf is a fictional brand. Forms send nothing.*
